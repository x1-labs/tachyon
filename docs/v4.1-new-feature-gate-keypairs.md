# X1 v4.1 — Feature-Gate Public Keys

Public-key changes to `feature-set/src/lib.rs` when rebasing X1 from upstream agave
**v4.0.3** (`14786d96e9`) onto **v4.1.2** (`182084b82a`).

X1 runs its own feature set: each upstream gate is re-declared under an X1-controlled public key,
with the upstream key kept as a `// solana <pubkey>` comment. Every gate below ships **inactive**.

| | v4.0 | v4.1 |
|---|---|---|
| `declare_id!` entries | 285 | **291** |
| gates in `FEATURE_NAMES` | 282 | **288** |
| `// solana` provenance comments | 109 | **117** |
| feature-set id | `2137973216` (`feat:7f6ee1e0`) | **`206231919`** (`feat:0c4ad96f`) |

291 = 284 upstream + 7 X1-only. 117 swaps = 110 pre-existing + 7 newly minted.
